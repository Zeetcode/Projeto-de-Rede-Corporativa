# 🖧 Projeto Prático de Rede Corporativa 

## 📖 Sobre o Projeto

Com o objetivo de aprofundar meus conhecimentos em um dos pilares fundamentais da Segurança da Informação e Cybersecurity, desenvolvi um laboratório prático no Cisco Packet Tracer simulando a infraestrutura de rede de uma pequena empresa.

O projeto foi concebido para reproduzir cenários encontrados em ambientes corporativos reais, permitindo a aplicação prática de conceitos essenciais de redes, segmentação, controle de acesso e administração de infraestrutura.

Além do aprendizado técnico, o laboratório proporcionou uma visão prática sobre a importância da arquitetura de redes para a construção de ambientes corporativos mais seguros.

---

## 🎯 Objetivos

- Consolidar conhecimentos em Redes de Computadores;
- Aplicar conceitos fundamentais de infraestrutura corporativa;
- Implementar mecanismos básicos de segmentação e controle de acesso;
- Desenvolver habilidades práticas voltadas à Segurança da Informação;
- Simular um ambiente corporativo funcional.

---

## 🏢 Cenário Implementado

A topologia simula uma pequena empresa composta pelos seguintes departamentos:

- Financeiro
- Recursos Humanos (RH)
- Marketing
- Tecnologia da Informação (TI)
- Servidores

Cada departamento foi segmentado logicamente por meio de VLANs, garantindo maior organização, segurança e facilidade de gerenciamento.
